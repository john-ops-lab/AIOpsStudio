# EasyOps 交付状态（公开投影）

当前行为以 [OpenSpec 主规格](../openspec/specs/) 为准。本页记录历史交付和验收边界，已移除现场名称、地址、源资产、模型配置、运行 ID、收据哈希与私有材料索引。它不是原始在线证据，也不代表当前公开提交已在任意环境完成验收。

## 已实现能力

- Chat 主入口、会话历史、固定输入框、上下文编辑和可折叠分析画布；用户可继续追问，独立轮次与父轮关联持久保存。
- 服务端账号与 admin/operator 权限；会话、消息、轮次、调用、证据和附件按可信用户归属隔离，管理员也不能默认读取他人私有历史。
- 用户文件和生成 Markdown 报告持久保存及授权下载；UTF-8 文本有界输入，二进制未提取状态明确。
- Skill、MCP 与模型的草稿、验证、发布、版本和管理；工具白名单、只写凭据、固定配置快照、单执行槽与持久事件。
- 原响应、模型阅读视图和模型报告分开；报告保留 `partial`、失败与未知，不用平台模板冒充模型结论。

## 首版历史基线

以下早于 Chat 多用户版本，不能代替新增能力的验收：

- 原后端基线为 51 项测试；预检有 7 项检查。模型协议样本、真实 CMDB 只读查询和浏览器工具试调曾成功；指标工具查询成功仅证明该查询完成。
- 最初两次分析在 token 预算边界停止，未产生真实模型报告。后续一次 `partial` 报告虽有模型正文，独立事实核对仍失败：阅读视图遗漏指标尾部回落和另一条时间序列，部分证据引用被缩写。
- 修正证据阅读视图后，后续一个有界 `partial` 样本完成原响应与报告对照。该结果不扩展为全部依赖覆盖、业务影响或根因验收，也不覆盖此前失败。
- 其他首败包括输出预算不足、查询缺少结束时间和源端不接受某些时间表示；后续使用显式 UTC 整秒窗口，并保留原错误。上述是历史限制，不声称当前外部接口版本行为完全一致。
- 历史初版交互协议检查证明持久消息和订阅方案可行；合成中断不等于完整断电恢复、生产租约或高可用验证。

## 仍待验证或实现

- 完整业务影响、跨源身份完整性、历史拓扑、根因可信度及用户接受按实际案例分别验收。
- 二进制内容提取、GLPI、自动告警触发、自动修复、Shell 执行、SSO 与生产高可用尚未提供。
- 完整断电恢复与告警 Webhook 联合场景仍待后续验证。当前中断保留已有证据并明确结束，用户可显式重试。
- 共享平台源身份不等同每用户的源数据授权；平台白名单不替代源端权限验证。

## 公开副本与运行边界

本机应用面向 Mac，部署入口已将状态目录、端口、数据库、可选 SSH 转发与数据源引导外置，通用用法见 [README](../README.md)。仓库不包含原运行实例、私有配置、用户历史、原始证据、模型端点或凭据。现有实例不因公开副本整理而迁移、重启或清空。

公开图片是完全新制的通用演示素材，不是实际截图或数据替换表。早期发布与当前历史清理分别由 [publish-public-repository](../openspec/changes/publish-public-repository/proposal.md) 和 [sanitize-public-history](../openspec/changes/sanitize-public-history/proposal.md) 跟踪。历史验收计数保持原义；本次配置改动的验证另记于当前变更，不把旧结果冒充当前提交的通过证据。
