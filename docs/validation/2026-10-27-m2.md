- 最终代码真 PostgreSQL 检查点/备份恢复：1 passed（0.63 秒）；真实 checkpoint/blob/writes、旧代次拒绝、非空检查点目标和复制期间并发写入均覆盖。

- 真 PostgreSQL HTTP 生命周期：稳定游标、归档筛选/恢复、含字节导出、预览删除/配额、删除后不可访问、报告同 ID 同字节修复全部通过。修复没有新增模型或源请求。

### MiniMax 与固定合成源

场景答案单独保存，模型执行进程禁止读取。模型初始消息没有预置事实答案，使用真实 MiniMax、真实本地 MCP HTTP 和固定合成源，未调用原业务来源。

- 分析成功样本：3 次实际模型请求、1 次 MCP 工具读取，自主正确补读 Skill 参考文件和保存证据片段，生成带有效引用的模型报告；1 条结构化事实与独立答案一致，Markdown 可下载且摘要一致，PostgreSQL 保存报告与 API 一致。
- 解释成功样本：1 次实际模型请求，工具/源/MCP 请求均为 0，关联原证据，原报告和用量不变。
- 补查成功样本：新 run/attempt 与父轮关联、独立预算，3 次实际模型请求和新源证据；原报告和用量不变。补查的额外模型计数结论因单位未被源支持而明确未通过核对，保留 partial，不将模型全部表述称为已验证。
- 模型配置质量：两组真实中文工具协议各 2 次模型请求，候选和已发布版本输入及逻辑源一致，服务端评价通过；实验发布保留原正式版，正式发布绑定当前门禁和试运行证明后切换。最终接口修复后受控回放门禁再次执行通过，未复用旧实现的证明。
- 上述仅代表合成源端到端及协议验收。单源、覆盖不足、未确认根因与价格未知继续明确显示，不代表真实业务 RCA 或用户接受。

## 首败与必要修复

1. 后端全量首跑 533 passed/1 failed/1 skipped，旧 AG-UI 终态重试额外提前解密凭据，与初次提交不一致；统一为入队查撤销、派发前解密，并保留 protocol_message_id，未修改旧断言。后续全量通过。并行定向曾触发既有自然报告超时时序首败，完整原断言在统一全量中通过，保留原失败记录。
2. 独立审查修复备份缺附件/Skill 包、目标覆盖检查点与并发新记录、源/目标目录重叠、Mac 路径别名、旧档案摘要重绑定；错误包清理、原源保持和当前授权隔离均有负例。
3. 修复连续解释的原证据链（逐节点重新授权、防环/跨会话/删除），恢复隔离时前端清旧缓存；MCP 未保存修改禁止试调，单价支持清除和未知缓存回执。
4. MiniMax 首次读取事实片段被独立测试策略拒绝：新场景未声明 field/unit/subject/observed_at 四个字段。仅在隔离测试策略增加四条明确规则，保留首轮结果、其他配置和原源；没有放宽产品默认策略。后续成功样本使用单独冻结版本。
5. 模型协议测试的 text schema 字段也先被隔离策略拒绝，未派发模型；显式注册这一字段后协议往返成功。候选/对照评估随后暴露模型测试 API 丢失 config_version 且把整份 model_snapshot 混入输入比较，修复真实入口并补 HTTP 回归，不通过修改评分分母绕过。
6. 固定门禁首跑失败无足够诊断，保留。补有界私有诊断后，第二次明确定位到私有 harness 对目录名 oracles 的过宽拦截误伤服务端 grader；仅修正 harness 为拒绝独立场景答案目录。固定合成执行子进程仍禁 oracle/网络，模型工具仍受 manifest 限制，产品未因该错误放宽。第三次正式门禁通过；模型测试接口修复改变实现指纹后，第四次重新执行门禁通过。
7. 新引导工具不再跳过质量门禁直接正式发布；只导入草稿。未发布模型不修改默认模型设置，以 default_model_pending 提示管理员发布后选择；真实管理 API 回归已覆盖。

## 原实例保护与资源

测试前对原数据库、私有配置/密钥、附件制品、容器及进程建立只读基线；中途复核全部一致。测试复用依赖，只使用一套有限资源的临时 PostgreSQL/API/Web/MCP，监测期间磁盘约 26–27 GiB、内存余量约 35–42%，未出现资源临界压力。临时 API/Web/MCP、限额 PostgreSQL 容器、浏览器测试页和无用数据库目录已按任务身份停止清理；临时密钥移除，保留必要私有首败/总结。原实例在清理前后均再次核对一致。暂存区对 90 个已知私有值及本次 MiniMax Key 常见编码扫描无发现，提交/推送仍执行正常安全门禁。
