# Chat 通用演示图生成要求（公开整理版）

制作一张简体中文运维工作台静态概念图。布局采用左侧深色导航、中央白色 Chat、右侧可折叠分析画布，蓝色主动作和柔和灰色边框；输入区保持明显、稳定、可见。

画面只使用独立通用文案：EasyOps、运维工作台、Chat、Skill、MCP、示例用户、示例环境、服务A、服务B、演示值、待核对。用户请求：“请分析示例服务的依赖关系。”；助手回复：“这是通用演示。业务结论与覆盖范围待核对。”。

不得包含实际主机、服务、节点、账户、地址、端口、模型配置、告警、运行或证据 ID，不显示时间戳、业务数值或现场曲线。不读取、重绘或拼接现场截图，不建立原值与演示标签的对应关系。

输出是完全新制的通用演示素材。旧文件名仅作为稳定链接保留，不表示新图继承旧图事实。图片不用于证明功能、业务结论或验收通过。
