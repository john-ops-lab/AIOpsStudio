# 前端实现与浏览器核对（公开投影）

本页保留历史浏览器检查的行为结论，所有检查在 Mac 本机执行。原始运行标识、源数据、报告哈希、私有截图和材料路径已移除。公开图片是完全新制的通用演示素材，不能作为历史验收截图。

## Chat 工作台结果

| 检查 | 历史观察与边界 |
| --- | --- |
| 构建 | TypeScript 与 Vite 通过，仍有上游大分包提醒 |
| 主界面 | 左侧会话、Chat 和固定输入框、右侧可折叠画布；用户可见流程统一称“分析” |
| 数据 | 真正读取服务端会话、消息、报告和附件；无可信结构化指标时不生成数值卡片 |
| 缺输入 | 问题先持久保存，明确 `not_executed`；补齐上下文后显式发送 |
| 文件 | 原生文件选择器上传用户材料；授权下载与保存字节一致，两轮报告各自对应原轮正文 |
| 多轮 | 两轮真实外部模型报告均 `partial`、`source=model`、`model_generated=true`；父轮关联保留，旧报告未覆盖 |
| 幂等恢复 | 执行中刷新恢复同一轮；终态重复消息不再派发；重新登录恢复原会话、轮次和文件 |
| 联核 | 浏览器操作与服务端联核 19/19，证明持久化链路，不证明完整业务覆盖 |
| 桌面 / 手机 | 1680×820 与 390×844，无页面整体横向溢出，输入框可见；控制台 error/warn 为 0 |
| 键盘 | Enter 打开对应证据，Escape 关闭后恢复原引用按钮焦点；手机画布关闭后恢复触发按钮 |
| 导航回归 | 告警到 Chat 的上下文预填、Skill 草稿表单、MCP schema/试调表单、账号管理通过；未提交表单不计作执行 |

首次真实模型尝试遇到超时及报告回合失败，产生 `platform_template`，`model_generated=false`。旧 oracle 曾误认非空 analysis 为模型报告，已纠正为失败。后续两轮真实报告未覆盖首次失败；用户接受仍待反馈。

## 展示修正及首败

- 早期画布同时显示摘要和完整 analysis，造成正文重复；Chat 仅识别加粗结论时会截断普通标题结论。修正后，存在 analysis 时画布只完整渲染一次，原始事实与元数据可折叠。
- 一次较长摘要仍会包含大表格。后来默认摘要上限收紧至 360 字，优先标题、加粗和引用结论，只取完整普通段落或句子，表格、代码、明细与完整证据 ID 不拆开；可展开完整回复。标题、引用、代码伪标题、GFM 表格、长度和证据引用断言通过。
- 手机首次加载报告曾自动打开画布并抢走 Chat 焦点。自动展开后改为仅宽屏首次产物；窄屏由用户显式打开。手机刷新复验无自动弹窗，输入框保持可见。

这些修正仅作用于展示，未改写持久报告和原响应。样式采用 navy 导航、蓝色动作、白色表面、冷灰边框与系统中文字体；公开通用图说明视觉方向，实际运行内容来自 API。

## 首版历史边界

早期运行工作台曾验证登录、Skill 生命周期、MCP 只读试调、告警字段和固定窗口、报告与证据读取。真实查询试调只证明该工具调用完成。首版报告曾遗漏指标尾部回落和另一条时间序列，独立事实核对判为失败；后续有界 `partial` 样本完成报告与原响应对照，不能回填为初次成功或完整根因验收。

完整证据引用可激活并读取同一条证据，缩写与代码块保持文本。只读页面核对不提交新分析。后续 Chat 规格已取代首版“终态关闭输入”的旧行为，当前终态支持新一轮追问。
