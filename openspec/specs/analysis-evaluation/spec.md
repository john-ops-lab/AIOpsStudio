# 独立分析案例与基线评估

## Purpose

用固定可见输入、Agent 不可见的独立预期和实际应用回放，分别核对已实现能力、失败与未验证边界；保留首败及真实计量未知项。

## Requirements

### Requirement: 输入与独立预期严格分离
评估系统 SHALL 分别保存固定 Agent 可见输入和独立 oracle；被测模型、源适配器和实际应用执行进程 MUST NOT 接收 oracle、案例 ID、未来才可见真值或预设答案。固定源快照 SHALL 只交给源适配器，模型 SHALL 只读取实际交付的消息和工具结果。评分 MUST 在执行完成后独立运行。

#### Scenario: 同一输入重放
- **WHEN** 从相同冻结输入与配置重复执行分析
- **THEN** 实际应用入口和运行队列被调用；修改独立 oracle 不改变模型请求和被测报告

#### Scenario: 执行进程尝试读取预期
- **WHEN** 执行适配器尝试读取 oracle 路径或通过符号链接绕过
- **THEN** 拒绝读取；该次执行不能按正常可比通过处理

### Requirement: 当前基线与版本冻结
评估系统 SHALL 固定基线源码、模型、Skill、工具 schema、摘要器、查询、隐私策略、案例、评分器及适配器身份和内容摘要；当前基线 MUST 测量原始 bd9a949。实现候选版 MUST 使用相同套件和可见输入比较，不覆盖首败或删除未来失败案例。不同套件或模型适配器 SHALL 分开记录，不得直接比较分数。

#### Scenario: 冻结版本不匹配
- **WHEN** 内容、源快照或被测快照与声明摘要不符或无法验证
- **THEN** 保留失败及差异，拒绝可比结论，不能作为可比通过结果

#### Scenario: 工作树正在并行修改
- **WHEN** 选择当前工作树测量候选版
- **THEN** 先复制并计算应用代码摘要，全部案例和重试运行同一份副本

### Requirement: 实际应用与 HTTP 回放
评估系统 SHALL 通过隔离实际 FastAPI 登录、创建运行、worker/Deep Agents 和终态/证据接口执行，不能直接将预设答案交给评分器。M1 合成模型 SHALL 保留真实模型 SDK 与应用 HTTP 出站守卫，只替换 HTTP transport；合成策略 SHALL 从实际消息及工具 schema 形成调用与回答。策略 fixture MUST 静态登记固定类型字段，未知类型/字段不得自动放行。

#### Scenario: 工具响应改变
- **WHEN** 工具实际返回的数据变化而 oracle 不变
- **THEN** 应用实际报告随所见数据变化，由独立评分器判定；不得复用手工预设答案

#### Scenario: 实际 HTTP 包含未登记字段
- **WHEN** SDK 发出的请求包含固定合成策略未登记的类型或字段
- **THEN** 应用守卫继续拒绝，评估器保留失败，不能动态扩权后声称原尝试通过

### Requirement: 严格与分项独立评分
评分器 SHALL 输出案例严格结果、事实/遗漏/因果/覆盖/引用/边界维度可核对分子与分母、失败分类、首败/重试/未执行及未知；任一适用断言失败、未知或评分错误 MUST 使严格结果不通过，不能被平均分抵消。引用 SHALL 核对实际保存证据及来源，而非仅匹配看似有效的引用文本。

#### Scenario: 尚未实现能力
- **WHEN** 出站、共享/撤权、裁决、references 或恢复样本未取得要求的实际操作收据
- **THEN** 保留样本及适用工作包，输出失败或未验证，不把未知算通过

#### Scenario: 后续尝试通过
- **WHEN** 第一尝试失败而同输入重复尝试通过
- **THEN** 总数仍由第一尝试确定；重复结果单列并引用首轮，不覆盖首败

### Requirement: 完整样本与未知计量
评估系统 SHALL 覆盖正常、缺失/陈旧、第二序列/尾部/分页、身份缺失/歧义、源失败、模型失败及无关证据，并保留实际请求次数、排队/执行/总耗时和用量未知项。未执行案例 MUST 留在案例分母；没有用量或价格收据时 MUST 输出 null 及原因，不得补零。

#### Scenario: 合成模型不提供 token
- **WHEN** 合成协议回放完成且模型未报告 token 或价格
- **THEN** 输出合成标签与 null/reason，不宣称真实模型质量、零费用或业务验收通过

#### Scenario: 失败模型保留初始计量
- **WHEN** Runtime 的初始 token 数为零但 provider 没有提供用量收据
- **THEN** 评估计量保持未知，不把初始零值当成实际用量

### Requirement: 私有原始观察与显式真实模型
评估系统 SHALL 仅将原始输入副本、模型请求、配置/运行/证据标识与操作收据写入仓库外全新私有目录；公开摘要 SHALL 仅保留必要合成计数、断言和边界。真实模型测量 SHALL 显式引用当前用户拥有、仓库外非符号链接的普通 0600 配置，优先 MiniMax，不静默切换模型或 provider；配置、认证头和 provider 原始错误 MUST NOT 被写入公开输出。

#### Scenario: 真实模型配置不符合边界
- **WHEN** 配置位于仓库内、权限不为 0600、不是当前用户拥有的普通文件，或未显式允许其他 provider
- **THEN** 在模型调用前拒绝配置，不回显敏感字段

#### Scenario: 真实模型与固定合成源
- **WHEN** 使用真实 MiniMax 对固定合成源进行有限尝试
- **THEN** 分别记录实际 HTTP 守卫与 token 收据，保留失败/partial；不得将模型协议通过或合成严格分数替代真实业务源与案例验收
