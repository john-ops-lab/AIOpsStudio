# 执行中断与一致恢复

## Why

M2 集成批次落实 #10，现有基础不足以覆盖完整组合与故障路径。实现旧执行器隔离、明确中断终态和显式重试、制品独立修复，并在隔离 Mac 演练数据库、制品、Skill 与密钥一致恢复。

## What Changes

每次任务写入、在途响应接受和 checkpoint 保存验证租约执行代次；旧 worker 无法覆盖新终态。恢复保留原冻结配置、预算与累计用量，不自动重发未知模型请求。用户显式重试创建冻结原配置的新 attempt，使用独立预算并保留旧用量关联；不会清零或改写旧 attempt。制品独立修复不调用模型。离线私有备份覆盖权威表、checkpoint、文件、Skill 及独立密钥摘要，只恢复到空隔离目标，缺件、错误密钥、目录重叠或最新撤权未确认时失败关闭。

## Impact

一个 M2 集成 PR，保留四份独立 OpenSpec 及分项验收。仅 Mac 开发/隔离测试；原实例配置、历史与附件保持。Case、人工裁决、自动告警、工单与高可用不属于本批。
