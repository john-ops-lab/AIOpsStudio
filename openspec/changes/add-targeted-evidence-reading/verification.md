# 验证

验证在Mac隔离开发副本进行；不改变现有API/Web、配置、密钥、历史、附件或业务源。

- Reader覆盖身份/固定版本、路径/符号链接/FIFO/大小/SHA、JSON/序列/时间/字段、剩余范围、稳定fragment、预算/重复计量、回执深拷贝和完整返回包字节。
- 独立审查发现并修复普通ledger绕过SHA、过滤后offset错认原始行、投影外字段借anchor引用；首败保留，回归不降低断言。
- 模型补读result经后续上下文重投影；无效selector形成可纠正安全错误。权限拒绝仍停止，缺数据不冒充空集。
- Web界面在独立合成API/Chrome验证覆盖状态、selector/下一段和片段撤权；构建通过。此边界不等于真实业务接受。

最终统一计数、PostgreSQL和MiniMax边界见 [M1验证](../../../docs/validation/2026-10-23-m1.md)。源端分页、Case共享、任意包导入、业务接受仍属后续或待验范围。
