# Proposal

## Why

竞品研究与现有路线图对照发现：主要分析流程已有实施项，但模型数据出站、发布前新旧质量比较、案例显式共享、人工裁决及若干运行配套仍缺明确交付与验收。用户已授权将缺口并入现有路线图、Issue 和设计，并同步 GitHub。

## What Changes

- 复用总 Issue #1 和 R01–R13，不创建新的实施 Issue；保留已有范围与未完成状态，补齐责任、依赖和验收。
- 将 R07 源权限与模型数据出站前置到 M1，补齐发布质量、受限参考资料读取、人工裁决、案例共享、队列配置、一致恢复和费用展示。
- 同步路线图、总体设计阶段映射、管理设计及增量设计，逐项核对远端正文和发布安全 CI。

## Capabilities

### New Capabilities

无。本次是规划与设计修订，`skip_specs: true`；不把未来目标写入当前应用主规格。

### Modified Capabilities

无。后续各实施 Issue 仍须先创建行为 delta specs，再开发并验收；本次 change 不代表这些功能已实现。

## Impact

仅文档、OpenSpec 规划记录及现有 GitHub Issues。保持应用代码、主规格、依赖、图片、数据库和私有运行配置不变；不部署、不调用模型或源系统、不执行故障注入。
