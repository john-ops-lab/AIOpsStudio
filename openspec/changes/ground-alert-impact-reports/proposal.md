# Proposal

## Why

M1 的结构化告警影响报告与确定性核对是完整设计 R04 的第一优先交付，消费 R02 对象/窗口和 R03 保存材料/片段合同。已有响应保存和文本引用不能保证实际读到尾部或数字、对象、解释正确。

## What Changes

新增稳定 fact/claim/report_version、保存值/单位/计数/方向/窗口核对、返回对象 result_identity、片段真实行号/投影校验及中文分层展示。模型原句与核验的结构化字段分开；第二序列、末端、正常对照和冲突保留，同源转述不增加独立支持。复用 R03 读取与 R07 最新授权。开发和测试在 Mac；真实模型验证优先 MiniMax，合成 SDK 结果不改称真实模型业务通过。

## Capabilities

### New Capabilities

- `grounded-reporting`：结构化告警影响报告与确定性核对。

### Modified Capabilities

无。通过新能力补强既有执行路径，不把历史结果升级为新验收。

## Impact

后端纯核对模块、runtime/材料读取集成、中文工作台、独立确定性 oracle 及边界回归；完整设计与整体发布由主集成统一收尾。不能把潜在拓扑等同已发生故障，不确认根因，不实现 R12 人工裁决或 R13 Case 共享，不升级历史/业务接受状态。
