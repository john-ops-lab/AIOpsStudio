## Why

现有 target、环境配置与参数名启发式不足以证明多个源查询了同一个对象、同一时段。跨环境同名、未映射对象、当前拓扑冒充历史及成功空结果混同失败会破坏分析可信度。

## What Changes

- 增加服务端确定性分析上下文，冻结完整对象键、版本化来源映射、UTC 具名窗口、源时钟偏差和查询目录。
- 歧义、缺映射、无历史有效期时保留明确缺口；身份不明进入 needs_input，禁止发出猜测对象查询。
- 显式查询目录绑定工具定义摘要、对象参数与时间参数；拒绝模型覆盖固定参数和相对时间。
- 查询目标与返回对象身份分开；仅按冻结的逐行或逐序列 `result_identity` 核验实际返回身份和四维来源范围，不根据指标标签名猜对象。
- 为证据统一保存完整、空、无权限、失败、陈旧、部分、历史不支持与未知覆盖语义；旧记录仅标记为未验证，不自动获得新能力。
- 运行详情只返回当前对象、窗口、版本和缺口；全局查询目录、源时钟表及原生身份映射保留在服务端配置快照。

## Capabilities

### New Capabilities
- `analysis-context`: 版本化对象、窗口、查询绑定和覆盖边界。

### Modified Capabilities
- 无；运行时集成由 M1 共同变更记录，模块本身不修改源系统。

## Impact

新增纯函数模块及合成边界测试，运行时在提交、调工具和保存证据前消费合同；管理 API 校验新格式，工作台展示固定对象、窗口、覆盖及澄清提示。应用、测试均在 Mac 独立开发副本；本 change 的合成检查不接触原实例、真实配置、凭据、模型及数据库，不安装源端组件。其他 M1 真实调用记录独立列示，不由本 change 的通过结果代替。
