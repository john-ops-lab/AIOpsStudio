# Proposal

## Why

首版工作台已交付，但分析可信度、管理组合验收、运行恢复及后续场景尚未形成统一的实施跟踪。将已确认方案发布为一个总路线图和十三个实施 Issue，使每项工作的依赖、交付边界和验收条件可直接检查。

## What Changes

- 在公共仓库创建一个总路线图 Issue 和十三个实施 Issue，按四个阶段编排，并互相链接。
- 新增正式开发路线图，更新设计索引及总体设计的阶段映射；已有实现、未来目标与验收结果分别表述。
- 对 Issue 正文及 Git 文档执行发布前脱敏检查，发布后读回核对数量、链接、范围与状态。
- 保留文档验证记录及 OpenSpec 任务记录。

## Capabilities

### New Capabilities

无。本变更仅发布规划与文档，`skip_specs: true`；不将未来能力写成当前主规格。

### Modified Capabilities

无。十三个实施 Issue 后续分别建立适用的 OpenSpec 变更。

## Impact

涉及 GitHub Issues、设计文档、文档入口及本变更记录。应用代码、依赖、数据库、配置、图片及现有运行实例均不变；不进行应用测试、模型调用或部署。
