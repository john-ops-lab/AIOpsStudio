# Proposal

## Why

总体、管理、研究增量和路线图分散在四份文档，存在历史目标与当前能力混读的风险。用户要求整合成一份完整最新设计，明确已实现与待开发，并同步 GitHub。

## What Changes

- 新建统一的完整设计，合并架构、交互、数据、配置、执行、安全、部署、验收与十三项开发工作包。
- 对照当前源码、主规格和历史公开验证，分别标记已实现、已实现但待验证、待开发和本轮不纳入；解决旧名词、模型视图、恢复和单账户等历史冲突。
- 更新文档入口与旧文档迁移提示，保留来源与既有链接；保留现有 Issue 编号、范围、状态与验收。
- 完成独立状态审计、读者审查、内容/链接/依赖检查、敏感信息门禁、远端读回及提交 CI。

## Capabilities

### New Capabilities

无。本次仅整合文档，`skip_specs: true`，不声明新应用能力。

### Modified Capabilities

无。应用主规格与代码不变；待开发部分后续仍分别建立实现 change 与行为 delta specs。

## Impact

仅文档和本次 OpenSpec 规划记录。原运行实例、私有配置、数据库、源系统及模型配置保持不变；不部署、不调用模型、不开展应用回归或故障注入。
